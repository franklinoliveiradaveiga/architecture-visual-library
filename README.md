# Architecture Visual Library

Biblioteca de componentes visuais e templates para diagramas de arquitetura de sistemas e soluções.

O objetivo principal é manter uma **linguagem visual consistente** entre projetos, facilitando a criação, reutilização e comunicação de arquiteturas.

## 🎯 Objetivo

- Centralizar componentes (shapes) reutilizáveis criados no Draw.io
- Garantir consistência visual e semântica entre diagramas de diferentes projetos
- Evoluir para outros conjuntos de formas e ferramentas (Archi, C4 Model, etc.)
- Disponibilizar templates de artefatos de arquitetura de solução

## 📦 Conteúdo atual

### Draw.io
- **Libraries**: componentes de arquitetura
- **Templates**: esqueletos de diagramas
- **Examples**: exemplos de uso

> Veja o [Catálogo](docs/catalog.md) para previews e descrição dos componentes.

## 🚀 Como usar (Draw.io)

### Opção 1 – Importar biblioteca localmente
1. Abra o [diagrams.net](https://app.diagrams.net) ou Draw.io Desktop
2. Vá em **File → Open Library from → Device**
3. Selecione o arquivo `.xml` desejado em `drawio/libraries/`

### Opção 2 – Via URL (recomendado para compartilhar)
     Use o link raw do GitHub: https://github.com/franklinoliveiradaveiga/architecture-visual-library/main/drawio/libraries/<library-name>.xml
