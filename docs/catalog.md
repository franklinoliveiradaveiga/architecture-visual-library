# Catálogo da Biblioteca

Este catálogo lista os componentes, bibliotecas e templates disponíveis no repositório.
Use-o como referência rápida para encontrar o que precisa e manter a consistência visual.

> **Como contribuir para o catálogo**  
> Ao adicionar um novo componente ou biblioteca, inclua uma entrada nesta página e um preview em `assets/previews/`.
